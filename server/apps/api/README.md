# CommerceOS API

Express and TypeScript API starter. The initial endpoint is `GET /api/v1/health`.

## Run locally

From the `server` directory:

1. Copy `.env.example` to `.env`.
2. Run `pnpm install`.
3. Run `pnpm dev`.
4. Open `http://localhost:4000/api/v1/health`.

The API currently uses an in-memory health endpoint and does not connect to a database yet.
